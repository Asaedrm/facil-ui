# Instalación

Instala el paquete `@facil-ui/react` en tu proyecto utilizando tu gestor de paquetes favorito:

```bash
bun add @facil-ui/react
```

O si utilizas npm / pnpm / yarn:

```bash
npm install @facil-ui/react
```

## Requisitos previos

- React 19 o superior
- React DOM 19 o superior

## Uso básico

```tsx
import { Button } from '@facil-ui/react';

export default function App() {
  return <Button variant="primary">Comenzar</Button>;
}
```
