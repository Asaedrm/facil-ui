# Fácil UI para React

Bienvenido a la documentación de **@facil-ui/react**. Esta librería proporciona componentes accesibles, modulares y altamente optimizados para construir interfaces consistentes en React 19+.

## Características principales

- ⚡ **Rendimiento:** Componentes ligeros y optimizados.
- 🎨 **Diseño Atómico:** Basado en tokens de diseño compartidos (`@facil-ui/tokens`).
- ♿ **Accesibilidad:** Cumplimiento con estándares WCAG y WAI-ARIA.
- 🛠️ **Storybook Interactivo:** Explora y prueba los componentes en vivo en [Storybook React](http://localhost:6006).
