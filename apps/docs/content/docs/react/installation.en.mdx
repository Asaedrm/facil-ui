# Installation

Install the `@facil-ui/react` package in your project using your preferred package manager:

```bash
bun add @facil-ui/react
```

Or using npm / pnpm / yarn:

```bash
npm install @facil-ui/react
```

## Prerequisites

- React 19 or higher
- React DOM 19 or higher

## Basic Usage

```tsx
import { Button } from '@facil-ui/react';

export default function App() {
  return <Button variant="primary">Get Started</Button>;
}
```
