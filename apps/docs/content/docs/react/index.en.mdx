# Fácil UI for React

Welcome to the documentation for **@facil-ui/react**. This library provides accessible, modular, and highly optimized components for building consistent interfaces in React 19+.

## Key Features

- ⚡ **Performance:** Lightweight, optimized components.
- 🎨 **Atomic Design:** Powered by shared design tokens (`@facil-ui/tokens`).
- ♿ **Accessibility:** Compliant with WCAG and WAI-ARIA standards.
- 🛠️ **Interactive Storybook:** Test and preview components live on [Storybook React](http://localhost:6006).
