# Button

El componente `facil-button` permite ejecutar acciones y disparar eventos dentro de aplicaciones Angular.

## Importación

```typescript
import { FacilButtonComponent } from '@facil-ui/angular';

@Component({
  standalone: true,
  imports: [FacilButtonComponent],
  template: `...`,
})
export class MyComponent {}
```

## Variantes

```html
<facil-button variant="primary">Primario</facil-button>
<facil-button variant="secondary">Secundario</facil-button>
<facil-button variant="outline">Contorno</facil-button>
<facil-button variant="ghost">Fantasma</facil-button>
```

## Tamaños

```html
<facil-button size="sm">Pequeño</facil-button>
<facil-button size="md">Mediano</facil-button>
<facil-button size="lg">Grande</facil-button>
```
