# Fácil UI for Angular

Welcome to the documentation for **@facil-ui/angular**. This library provides accessible components built with Angular Signals and Standalone Components for Angular 22+.

## Key Features

- ⚡ **Modern Angular:** Native Standalone Components and Signals.
- 🎨 **Visual Consistency:** Same design tokens as `@facil-ui/react`.
- ♿ **Accessibility:** WAI-ARIA and keyboard navigation support.
- 🛠️ **Interactive Storybook:** Test and preview components live on [Storybook Angular](http://localhost:6007).
