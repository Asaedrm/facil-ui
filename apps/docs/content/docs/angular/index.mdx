# Fácil UI para Angular

Bienvenido a la documentación de **@facil-ui/angular**. Esta librería proporciona componentes accesibles, basados en Angular Signals y Standalone Components para Angular 22+.

## Características principales

- ⚡ **Angular Moderno:** Standalone components y Signals nativos.
- 🎨 **Consistencia Visual:** Mismos tokens de diseño que `@facil-ui/react`.
- ♿ **Accesibilidad:** Soporte WAI-ARIA y navegación por teclado.
- 🛠️ **Storybook Interactivo:** Explora y prueba los componentes en vivo en [Storybook Angular](http://localhost:6007).
